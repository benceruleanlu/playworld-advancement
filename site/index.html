Iterate hackathon, Track 4: World Models

How long can a generated world hold together while an agent plays in it?

We take an open world model and add inference-time memory, state tracking and re-anchoring, with no training, to push its PlayWorld score past Genie 3 (2.12). Every one of our numbers is scored by the benchmark's own Gemini 3.1 Pro verifier and traced to a commit; reference rows are the PlayWorld paper's. Scores run from 1 to 5; higher is better.

Where we can win

PlayWorld scores four task families. Genie 3 is strong on geometry and control but weak once something leaves the frame or has to change over time. Those two families are where inference-time memory and state tracking should pay off, so most of our work targets them. Bars start at 1, the score floor. "Ours" is one run, the same one as on the ruler above, never a per-family best-of-many; it is hatched while that run covers only part of the benchmark.

What we changed

Each change wraps the world model's generate() call; the model weights are never touched. A change only counts as a win once a closed-loop run beats its baseline by more than 2x the verifier's pass-to-pass noise. Evidence links point at the logged runs below.

How we measure

A world-model score is easy to inflate by accident: replay recorded actions instead of letting an agent play, tune on the test set, or call a lucky verifier pass a gain. This is the protocol every reported number goes through, and where each rule lives in the code (or, where it is only a team convention, we say so).

Fixed splits

171 tasks. A seeded 24-task dev set (6 per family) for iteration; 147 held out, unscored until code freeze.

Closed-loop play

An LLM agent (gpt-4.1-mini) watches each chunk and picks the next action. No replayed dataset actions in final numbers.

Official verifier

Upstream Gemini 3.1 Pro rubric judge at upstream FPS, resolution, JPEG and sampling. The judge sees the same neutral model name for every run.

Repeat passes

Score every rollout 2+ times. Report mean and pass-to-pass std per family.

Noise rule

A delta under 2x the pass std is labelled noise, never a win. With one pass, the paper's variance (std 0.105) is used.

Traceable log

Each run appends a row to results/experiments.csv with commit SHA and launch branch. This page reads it live.
